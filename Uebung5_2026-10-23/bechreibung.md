
Mit dieser Webseite kann ich Serien anzeigen, hinzufügen, ändern und löschen.

## WAs habe ich umgesetzt

- Deno startet den Server.
- Drizzle arbeitet mit der Datenbank.
- SQLite speichert die Serien.
- HTML und JavaScript zeigen die Webseite.
- REST Client für ausprobieren von CRUD Anfragen.

## Eine Serie hat

- eine UUID
- einen Titel
- einen Status(Geplant, schaue ich gerade, abgeschlossen)


zuerst im ordneer`deno task dev` ausführen. Dann `http://localhost:8000/` öffnen.
und in File requests.rest kann man rest client benutzen um die Anfragen auszuprobieren.
